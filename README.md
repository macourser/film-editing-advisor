# 导演与剪辑指导 · Film Editing Advisor

让 AI 作为创作搭档，围绕作品表达、实际素材和粗剪提出导演与剪辑判断，并按需比较有来源的导演、剪辑师与具体影片的方法。

适合这样的提问：

- 这段为什么有内容，却没有情绪？
- 应该保留这次停顿，还是提前切到听者？
- 同一组素材，换一种叙事或剪辑方法会怎样？
- 想借鉴某部影片，哪些手法适合当前素材，哪些需要补拍？

## 三种职责

| 职责 | 工作重点 | 交付内容 |
|---|---|---|
| 导演顾问 | 主题、人物关系、视角、情绪运动 | 创作判断、表达方向、拍摄与补拍建议 |
| 剪辑指导 | 结构、信息、表演、节奏、空间与声音 | 具体修改意见、段落重组、切点与取舍 |
| 风格顾问 | 具体影片与创作者合作中的方法 | 同素材不同处理、推荐理由、条件与代价 |

## 安装

这是一个独立的 Agent Skill，仓库根目录的 `SKILL.md` 是入口。

### 通过 Skills CLI

```bash
npx skills add macourser/film-editing-advisor --skill film-editing-advisor
```

按安装器提示选择使用的 Agent 与安装范围。

### 在 Codex 中安装

向 Codex 发送：

> 请使用 $skill-installer 安装 https://github.com/macourser/film-editing-advisor 仓库根目录中的 film-editing-advisor 技能。

Codex 的 Skill Installer 支持从其他仓库下载技能。参见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)。

### 手动放入技能目录

将本仓库内容保存在宿主可发现的 `film-editing-advisor` 文件夹中，确保该文件夹直接包含 `SKILL.md`。具体发现目录以所用 Agent 的当前文档为准；Codex 的项目级目录可使用 `.agents/skills/film-editing-advisor/`。

## 调用示例

```text
请使用 $film-editing-advisor 担任这部作品的导演与剪辑指导。
先理解表达目标，复述要求并给出计划，经我认可后审看素材。
指出最值得改的地方，解释理由、修改方法和代价。
需要时比较不同风格的处理，并给出你的推荐。
```

默认工作方式是先复述、出计划、经用户认可后操作。已有认可在明确范围内持续有效；后续分析不会为每一个读取动作重复确认。

风格比较也可以单独提出：

```text
我有一段人物犹豫后离开的素材。
请比较保留完整表演、通过细节重组、增加另一条行动线三种处理。
说明它们分别怎样改变观众关注的问题，以及现有素材能不能实现。
```

## 首批风格方法卡

| 具体参照 | 重点 |
|---|---|
| 王家卫／张叔平：《花样年华》 | 重复、缺席、细节与音乐 |
| 侯孝贤与《刺客聂隐娘》剪辑团队 | 连续表演、镜头保留、何时需要切开 |
| 诺兰／Lee Smith：《敦刻尔克》 | 多线压力、交叉剪辑、信息清晰度 |

从[风格库索引](references/style-library.md)进入。另附[同一场景的三种处理](references/compare-one-scene.md)，展示角色如何比较方案并作出推荐。

卡片分清来源支持、看片观察和创作推演。导演姓名用于检索；实际讨论落到具体作品、方法及合作贡献，不把作者整个生涯压缩成固定秒数、滤镜或必用转场。

## 能力与验证范围

- 这是以创作判断为核心的指令与参考资料包，本身不包含剪映、Premiere 或其他剪辑软件的自动化接口。
- 能否读取视频、听音轨或执行剪辑，取决于宿主当前具备的工具及用户授权。文字、截图和抽帧只支持相应范围的判断。
- 首批三张卡基于创作者访谈归纳，来源于 2026-10-24 核对；尚未完成对应影片的逐镜拉片。
- 已完成技能结构、元数据与内部引用检查；尚未用真实视频验证审片质量。
- 纪实、新闻和工作记录需保留事实与时间关系，尤其注意交叉剪辑可能暗示同时性或因果。

## 贡献

欢迎提交真实使用中的问题、匿名化示例和有依据的新方法卡。新增卡请标明作品与创作范围、原始来源、可迁移方法、素材条件和边界；实际拉片另记版本与时间码。

不要提交私人素材、未获授权的影片文件、完整访谈转载或编造的时间码。单个案例的偏好不直接升级为所有作品的规则。
